## 🇷🇺 О проекте

**GreenBLOX** — это игровое приложение, созданное с нуля с особым вниманием к атмосфере, визуальному стилю и игровому процессу.

Исследуйте мир игры, взаимодействуйте с его элементами и создавайте собственный игровой опыт. Проект продолжает развиваться, поэтому в будущем GreenBLOX будет получать новые возможности, улучшения и обновления.

> 🌱 GreenBLOX — это место, где идеи превращаются в игровой мир.
